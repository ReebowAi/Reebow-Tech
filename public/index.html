Built for Production Scale

Every feature engineered for real-world reliability — not just demo happy paths.

Telegram-Style Chat

Tabs: Chats, Contacts, Calls, Settings. Bottom nav on mobile. Swipe gestures. Message bubbles with tails. Image paste/drop. Read receipts. Typing indicator.

  • Real-time via Socket.io
  • Offline queue + auto-retry
  • Image compression (client-side)
  • Markdown + link previews

Admin Control Tower

Single-pane dashboard: live visitor list with online dots, geo flags, search, full history, send text/images, initiate calls, inject video clips, delete conversations.

  • Password-protected (configurable)
  • Multi-visitor concurrent views
  • Call logs with duration
  • Mobile-responsive sidebar

Video Call Loop (Clip Injection)

Pre-record persona clips (Annie, Craig, custom) → admin clicks → visitor sees lip-synced video instantly. Zero GPU. Zero WebRTC complexity. Works on $0 hosting.

  • MP4 clips, baked audio = perfect sync
  • Persona switcher (multi-character)
  • Looping "listening" states
  • Realism filters (grain, blur, warmth)

Geo Detection & Localization

IP → country, city, flag emoji, timezone, ISP. Auto language switch (EN/FR/ES/AR/PT). Admin sees visitor location instantly. No external API keys needed (ip-api.com free).

  • 45 req/min free tier
  • Cached per session
  • RTL language support
  • Custom admin name per visitor

Offline Resilience

Service Worker caches app shell + clips. Messages queue locally when offline → auto-flush on reconnect. Heartbeat detects disconnection. Visitors never lose input.

  • Workbox-style precaching
  • Background sync (when supported)
  • Connection state UI
  • Auto-reconnect with backoff

PWA Installable

Web App Manifest + Service Worker = "Add to Home Screen" on iOS/Android/Desktop. Full-screen standalone mode. Push notification ready (VAPID keys).

  • Custom install banner
  • Shortcut icons (Chat, Calls, Settings)
  • Offline-first caching strategy
  • Badge notifications

Security Hardened

Helmet CSP, rate limiting (global + login), secure httpOnly cookies, MongoDB Atlas IP whitelist, env-only secrets, session TTL, CORS locked to your domain.

  • No hardcoded credentials
  • Brute-force protection
  • Input validation + sanitization
  • Audit logging

Multi-Tenant SaaS Skeleton

Tenant isolation via tenantId. Payment webhook → auto-provision tenant + unique admin password + return branded URLs. Stripe / NOWPayments / Paystack ready.

  • Isolated visitor lists per tenant
  • Custom admin name per tenant
  • Webhook signature verification
  • Clone & deploy for clients

Manual Deploy Steps (Any Node Host) 
# 1. Clone & install
git clone https://github.com/your-org/reebow-platform.git
cd reebow-platform && npm ci --production

# 2. Configure environment
cp .env.example .env
# Edit .env with your values (MongoDB URI, secrets, domain)

# 3. Build front-end assets (if using build step)
# npm run build

# 4. Start (production)
NODE_ENV=production npm start

# 5. Process manager (PM2)
npm i -g pm2
pm2 start server.js --name reebow --env production
pm2 save && pm2 startup
